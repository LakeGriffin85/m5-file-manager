# Changelog

## 1.1.0 – Public preview

- First standalone public edition, with a fresh repository history.
- Neutral app identity and artwork; no deployment-specific defaults or personal resources.
- English and German app UI, including dialogs, status messages and errors; language selection preserves open editors and CSV data.
- Independent preference domain and user-relative backup locations.
- Existing USB file operations, checked transfers, previews, terminal, backup and live-sync behavior retained.
- Universal local build and preview ZIP packaging. Developer ID notarization and public distribution remain separate steps.
